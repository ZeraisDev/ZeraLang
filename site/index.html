Zeralang

A bi-modal programming language. Write in highly-readable English syntax, convert to standard C-style code, and execute at native speeds.

Download Windows Read Docs
⚡ 1.5x faster than CPython on pure numeric loops (Bytecode VM)

// read_mode.zera (English)

set x to 10
set y to 20
set result to x + y

if result greater than 25 then
    show "Greater than 25"
otherwise
    show "Less than 25"
end

// write_mode.zera (C-style)

x = 10
y = 20
result = x + y

if (result > 25) {
    show "Greater than 25"
} else {
    show "Less than 25"
}

# Install & Run

Portable Windows build. No Administrator rights required. Just extract and run.

  1. Download and extract the .zip file to your Desktop or Downloads folder.
  2. Open the extracted folder and double-click run.bat.
  3. A Command Prompt terminal will open. Type zera demo.zera to run an example program.
  4. Type zera to enter the interactive REPL, or zera benchmark.zera to run the speed test.

# Quickstart & Syntax

Variables & Math

Zeralang supports standard operators and compound assignments. Variables are dynamically typed.

x = 10
y = 20
total = x + y
total += 5     // Compound assignment
show total

// String interpolation is supported natively
show "Total is {total} and half is {total / 2}"

Control Flow

Use if, while, and for each loops.

if (total > 30) {
    show "Big"
} else {
    show "Small"
}

i = 0
while (i < 3) {
    show i
    i += 1
}

for each n in range(3) {
    show n
}

Functions & Lambdas

Standard function definitions and inline anonymous functions.

func add(a, b) {
    return a + b
}

// Lambda
multiplier = func(x) {
    return x * 2
}

show add(5, 10)
show multiplier(5)

Object-Oriented Programming (OOP)

Create classes with fields, constructors, and inheritance. Drop the new keyword—just call the class.

class Animal {
    field name

    construct(name) {
        self.name = name
    }

    func speak() {
        return "{self.name} makes a sound"
    }
}

class Dog extends Animal {
    func speak() {
        return "{self.name} barks!"
    }
}

d = Dog("Rex")
show d.speak()

# The Bi-Modal Converter

The core feature of Zeralang. You can write in one syntax and instantly convert it to the other. The Abstract Syntax Trees (AST) are mathematically identical.

Convert to Read Mode

Converts standard C-style code into English-like syntax.

zera --convert-read main.zera

Convert to Write Mode

Converts English-like syntax back to standard C-style code.

zera --convert-write main.zera

Verify Round-Trip

Parses the code, converts it, re-parses it, and verifies the ASTs match losslessly.

zera --roundtrip main.zera
